# 国风 AI 漫剧镜头工艺总库

**一个入口，八卷分类。** 覆盖从"看懂一条爆款"到"写出可直接投喂 Seedance 的成品提示词"的全链路。

> **最高优先（2026-09-22 用户定档）**：写修仙 / 仙侠打斗，**一律对标用户本人发来的标杆视频，参数全部取自实测，不准凭感觉估**。参照系在 **H 卷**。

> 全局规则：无 BGM、无字幕；提示词末尾统一挂 `--no bgm subtitle`；默认 9:16 竖屏；角色脸必须由用户提供参考图锁 `@handle`。

**三层正交**：先用 **A** 定类型与节拍 → 再用 **G** 选特效元件（一镜 1-2 个，最多 3）→ 最后挂 **B** 的质感层升级。
**特效颜色必须服从 B 卷的三色控制**，否则一次挂两个色系必廉价。

**特效速配**（详见 G 卷第三章）：剑修→青蓝剑气+剑罡护体｜雷法→电光缠绕+冲击波｜魔修→黑雾气场+粒子炸裂｜佛门→圣光光晕+丁达尔｜拳脚→拳风+震尘｜快刀→刀芒瞬闪+残影｜都市甜宠→温柔光斑+柔光｜都市夜戏→霓虹散景+雨夜｜悬疑恐怖→诡异微光+黑影虚化。

## 三条底层规律（先记这个）

1. **一条爆款只服务一个情绪功能**——美 / 燃 / 痛 / 大 / 爽，只占一个。
2. **视觉符号要极致**——每类镜头必须有一个可被记住的符号，占画面 1/3 以上。
3. **时长克制、技法集中**——冲击帧、震屏只占镜头前 1/3。

## 修仙 / 仙侠打斗强制标准（用户 2026-09-22 定档，写任何打斗提示词都先过这六条）

0. **参照系锁死：只认用户发来的标杆片，参数取自 H 卷实测。** 用户新发视频 → 先按 H 卷第六章脚本量化（切点/镜长/动作强度/亮度）→ 入库 → 再动笔。**绝不凭感觉估镜数与节奏。**
1. **按 F 卷零章「密度档位表」选镜数**，不要自己估：15 秒 = 6 镜、30 秒猛档 = 12 镜 × 2.5 秒（每段只切一次）、30-35 秒稳档 = 6-8 镜 × 4-5 秒（段内不切跟拍）。
2. **每镜 ≥3 个动作**，动作之间用「紧接着／不等落地便／随即／被震开后立刻」串联，不许停顿、不许摆 pose。
3. **首帧图必须是已经交手的动作姿态**（两刃顶死／一剑下劈被架住），绝不能是两个小人站定对望。首帧站着，整段都站着。
4. **开场静止 ≤1 秒**，之后必须一直在动；每段静态场景句只留 1 句，其余全给动作。
5. **暗调低饱和**（亮度中位 43-45）、三色控制、**闪白全片 ≤1 次且放在 55-60% 处**、环形冲击波全片 1 次、血线只一道、每镜写明双人同框。

每段 EN 提示词 ≤200 词；成片若空，先查这六条，不要靠加切镜救。

**标杆片定档**：猛档原型 = 17.5 秒片（8 切 / 镜长 2.18 秒 / 动作强度 6.3 / 闪白 1 次在 58%）；稳档原型 = 35 秒片（8 切 / 镜长 4.4 秒 / 动作强度 2.8 / 无闪白）。用户说"照那些视频来"＝取猛档原型。

## 四个病根（画面廉价先诊断）

| 病根 | 表现 | 药方 |
|---|---|---|
| 材质缺省 | 塑料感、玩具感、光滑无纹理 | 材质词 ≥5 个，覆盖材料+工艺+纹样 |
| 景深缺省 | 画面平、像贴纸 | 三层景深：前景遮挡+中景主体+远景剪影 |
| 光源缺省 | 光像贴图、凭空发光 | 三层布光，每道光有出处，体积光配介质 |
| 完美缺省 | 假、CG 味重 | 加"不完美"：磨损/剥落/褶皱/灰尘/氧化 |

## 标准工作流

0. **选身份（前置，不可跳过）**：先调 `ai-drama-crew` 选主身份（导演 / 网文 / 武指 / 仙侠国漫 / 喜剧·颠 / 甜虐），定审美基线与色彩三色。**用户不会每次明说身份，必须主动选**——题材+情绪即可反推：打斗→武指、仙侠大场面→仙侠国漫、搞笑→喜剧·颠、恋爱→甜虐、整体定调→导演。主身份只许一个。
1. **判需求**：题材 + 情绪 + 用途（用户说得再短也够，其余按 F 卷默认补全）。
1.5 **对标 H 卷**（题材是修仙/仙侠打斗时必走）：查标杆片实测，定镜数 / 每镜秒数 / 动作强度 / 闪白位置 / 亮度；用户发了新视频就先量化再入库。
2. **定类型**：从 A 卷 8 类里锁定 1 类（不要混）。
3. **选特效**：G 卷 22 类里挑 1-2 个主特效（大招最多 3），写清来源与形态。
4. **排节拍**：C 卷取 15 秒时间轴，过密就拆段。
5. **加质感**：按镜头重要性选 A/B/C 档，挂 B 卷材质词与景深灯光（特效配色服从三色控制）。
6. **写成品**：中英双语，末尾 `--no bgm subtitle`。
7. **落盘自检**：跑 F 卷两道自检（中文区扫孤立英文 + BOM/CRLF 转码），再交付。

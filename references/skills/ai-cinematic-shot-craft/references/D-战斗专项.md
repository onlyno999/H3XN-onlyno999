# D 卷 · 战斗专项（打斗 / 施法 / 对撞）

写打斗时先建**空间契约**，不写清这个，双人必崩（糊成一团 / 换脸 / 越轴）。

## 一、空间契约（双人必写）

| 项 | 规则 |
|---|---|
| **三锚点** | 固定三处地标（如：左侧残碑 → 中央对决石台 → 右侧倾倒经幢），全程不换 |
| **站位** | A 在画左、B 在画右，全程不越轴 |
| **唯一换位** | 一方越过另一方头顶时，转**高位俯拍做中性重建**，落回立刻复位侧面轴线——这是唯一合法的轴重建 |
| **开场态** | 开场即已在打（两刃顶死），不对视、不热身 |

## 二、角色三重区分锁（防糊第一道防线）

服装 + 能量色 + 武器，**三样全不同**。例：

- `@女修A`：白衣银纹 · 冷蓝冰霜 · 长剑
- `@女修B`：绯衣赤纹 · 赤金雷火 · 双短刃

跨镜复用同一 `@handle`，首帧用用户提供的模特参考图锁五官。

## 三、动作脊柱（GFSM 六段式摘要）

1. 开场已在打，接触点爆火花
2. 抢中线连招（**3 招内**分出压迫链：横切逼守 → 上撩挑起 → 回旋劈落）
3. 受击方贴身侧闪格挡 → 被震开 → 半步卸力 → 借锚点反蹬回场
4. 被压至锚点 → 反蹬腾身越顶换位（高位俯拍重建）
5. 半空交错，各自凝聚能量形态（冰霜巨轮 / 雷弧）
6. 同时推出对撞 → 终结 → **不以摆 pose 结束**（滑停 + 震颤 + 血线 + 余波）

**每记攻击都必须有格挡 / 卸力 / 受力反馈**；能量轨迹不得遮蔽关键接触点。

## 四、施法三拍子（类型 5 必守）

| 拍 | 时长 | 内容 |
|---|---|---|
| 冲击帧 | 0.0-0.5s | 全屏闪白、能量中心炸开、圆环冲击波、尘土碎石掀起 |
| 震屏 | 0.5-0.8s | 摄像机剧烈抖动，**幅度先大后小** |
| 回归平稳 | 0.8-2.0s | 烟尘缓落、画面回稳、接角色反应 |

## 五、双人专属负面词（**必加**）

`fused bodies, merged characters, identity swap, morphing between two characters, extra limbs, extra fingers, deformed hands, lowres, blurry, plastic skin, over-smoothed face, waxy, watermark, text, logo, subtitle`

前四条是防糊防换脸的关键，单人镜头不用加。

## 六、结局处理

打斗结局**优先定成两败俱伤**而非分胜负（背对背滑停 → 各自单膝 → 各一道血线 → 余波冲击波扩散），方便连续剧接下一集。

可选：碾压秒杀（一招完事，压迫感）、虐恋收手（剑到咽喉停住）、悲壮反杀（重伤反杀后陨落）。

## 七、音效对齐（无 BGM）

双刃顶死金属高频尖响 → 连招碰撞 → 蹬锚点炸石 → 越顶破风 → 半空能量嗡鸣攀升 → 对撞低频爆轰（与震屏同帧）→ 崖面崩塌轰响 → 交错撕裂声 → 双膝落地闷响 → 余波低频渐远

低频轰击**必须与震屏同帧**，否则震屏看着假。

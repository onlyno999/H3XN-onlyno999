# C 卷 · 节奏与编排

定「时间怎么排」。与 A 卷（拍什么）、B 卷（贵不贵）正交。

## 一、15 秒单镜标准节拍（蓄·爆·连·落）

| 段落 | 时长 | 内容 | 功能 |
|---|---|---|---|
| 蓄 | 0-1.5s | 低机位仰拍，角色悬空/立定蓄势，法器亮起，法阵由暗转亮 | 定调、给期待 |
| 连 | 1.5-5.5s | 冲入敌阵，高速环绕跟拍，连招，气浪震飞，运动模糊 | 爽感主体 |
| 爆 | 5.5-7.8s | 结印前推 → 闪白 + 冲击波 → 震屏先大后小 → 回稳 | 峰值（施法三拍子） |
| 落 | 7.8-13s | 终结一击 / 反转 / 战损 | 结果 |
| 收 | 13-15s | 收势回眸，余尘飘落，侧逆光勾轮廓 | 记忆点 |

**节拍可整体复用，换版本只替换 4 个变量**：主体（女修/男修/妖兽/双人/Q版）、视觉符号（符箓/雷纹/骨爪/龙鳞）、能量色（冷蓝/赤金/紫雷/墨黑/血煞红）、情绪（燃/悲壮/碾压/虐恋/觉醒）。

## 二、三种爆款编排结构

- **A 美貌暴击型**：空镜 → 面部特写 → 战损回眸 → 空镜收（静·美·痛·静）
- **B 高燃爆发型**：帅镜蓄力 → 施法爆发 → 高速武打 → 群像溃散（蓄·爆·连·落）
- **C 史诗氛围型**：大场景 → 群像冲锋 → 旋涡对峙（广·压·燃）

结构 B 是 15 秒打斗的默认骨架。

## 三、拆镜规则

15 秒单镜信息过密时按**情绪拐点 / 换气点**拆段：

- 拆点选在「能量聚势尚未推出」「震屏回稳后」「人物落定前」
- **A 段尾帧 = B 段首帧**，同机位、同光比、同一能量色相
- 常用切法：8s + 7s（激烈打斗）、5s×3（三重加码加强版）、**6s×5（30 秒高密度首选）**

**段长与密度（2026-09-22 实测，推翻过一次结论，以本节为准）**：
- 段长不是越短越好。空片的根因是**动作少**，不是**段长**。30 秒用 10s×3 会空，是因为段内只写了三招，不是因为 10 秒太长。
- 正确拆法：**30 秒 = 6 段 × 5 秒**，每段**一镜到底、镜头跟拍、段内不切**，段内塞 4-5 个连续动作。切点只落在段接缝处（5 次）＋ 关键节点，全片约 6-8 镜。
- 曾误判为"每 1.2 秒切一镜"，排出 24 镜 → 画面碎、每次切镜都要重新构图、极易崩。**禁止碎切**。
- 标杆片数据：35 秒 / 硬切 8 次 / 平均镜长 4.4 秒 / 中段 17 秒不切镜照样不空。

**段内写法**：写明跟拍方式（手持跟拍／环绕／后拉升高／正面跟随／推近），动作之间用「紧接着／不等落地便／随即／被震开后立刻」串联，末尾加「全程不停顿、不摆姿势、镜头持续跟随」。

## 四、三种加码变体（"更激烈"时往上叠）

**① 时间凝滞**
敌影与碎石在半空悬停 → 角色穿行连斩 → 时间恢复瞬间敌群同帧炸散。
音效配合：凝滞处环境音骤静，恢复瞬间爆响。

**② 战损美学**
衣袖破碎、发丝散乱、嘴角/颈侧一道血线、单膝落地、缓缓抬眼冷冽一笑。
注意：血线只写一道，多了变恐怖片。

**③ 双人对波**
冷蓝 vs 赤金两道能量柱在正中狠狠对撞 → 冲击环层层外扩 → 一方压制吞没另一方。
音效：低频嗡鸣攀升 → 对撞低频爆轰（与震屏同帧）→ 撕扯嗡鸣。

**④ 能量灌地**（蓄势变体）
单膝低伏、长剑插地、电流顺剑身灌入地裂光纹，光纹向四周蔓延。

## 五、用途分流（同一内容两个方向）

| 用途 | 处理方式 |
|---|---|
| **宣传号** | 钩子前置——0-1.5s 直接上最高能画面（闪白/对撞/美貌特写），不铺垫；循环友好（首尾帧可接） |
| **剧情用** | 节拍完整，蓄势不能省；结尾留悬念位或情绪落点，方便接下一集 |

用户说「XX 做宣传号、YY 做剧情」是**方向说明**，不是改写指令——除非明确要求，不要自动改造内容。

## 五之二、★ 峰均比：节奏求平不求陡（2026-09-22 三条对标片实测）

**峰均比 = 逐 0.5 秒强度曲线的峰值 ÷ 均值。**

| 片 | 峰均比 | 观感 |
|---|---|---|
| A 仙侠法术 17.4s | **2.06** | 全程紧凑 |
| B 3D国漫 35s | **2.25** | 稳，长镜不空 |
| C 真人武侠 75s | 3.60（录屏黑边拉高，实际更低） | 稳 |
| **我们 V4 30s** | **3.00** | 猛一下 → 塌一段 → 再猛一下 |

**红线：峰均比控制在 2.0-2.5。** 超过 2.8 就会明显感到「断续」。

正确形态是**全程在均值上下小幅波动**，而不是靠几个爆发点撑场面：
- 低谷**单个不超过 1-1.5 秒**（对标片最长塌陷 1.0 / 1.5 秒）
- 我们 V4 的塌陷是 0-2.5s / 7.5-12s（**4.5 秒**）/ 27.5-29.5s —— 三处加起来 9 秒，占全片 30%

**检查动作**：跑出逐 0.5 秒曲线后，先算峰均比，再找连续低于峰值 18% 的区间。
峰均比 >2.8 或任意单一空档 >1.5 秒，就是节奏不合格，跟切了多少刀无关。

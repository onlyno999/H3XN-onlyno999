## 第一章 总论：便宜 AIGC 的四个病根

豪华与廉价的差别不在提示词长短，在是否治好了这四种缺省：

| 病根 | 表现 | 病因 |
|---|---|---|
| **材质缺省** | 塑料感、玩具感、光滑无纹理 | 不指定工艺与材料，模型默认给均匀光滑表面 |
| **景深缺省** | 画面平、像贴纸 | 只有主体 + 空白背景，没有前后层 |
| **光源缺省** | 光像贴图、凭空发光 | 光源无出处，体积光内无介质 |
| **完美缺省** | 假、CG 味重 | 无磨损、无褶皱、无灰尘、无氧化 |

**豪华 = 逐一治这四病。** 对应三支柱 + 一条铁律：

- 支柱一 · 材质词 → 治塑料
- 支柱二 · 景深层数 → 治平
- 支柱三 · 光源物理性 → 治贴图
- 铁律 · 加"不完美" → 治假

## 第二章 豪华感三支柱

### 支柱一｜材质词（治塑料）

**规则**：每条提示词材质词 ≥ 5 个，且必须同时覆盖 **材料 + 工艺 + 纹样** 三类。

**材料词库**

| 类别 | 中 | EN |
|---|---|---|
| 石材 | 汉白玉 / 青石 / 斑驳石壁 / 湿冷岩面 | white marble / bluestone / weathered stone / damp rock |
| 金属 | 做旧铜 / 鎏金 / 錾刻银 / 锈蚀铁 / 冷锻钢 | patinated bronze / gilded / chased silver / rusted iron / cold-forged steel |
| 织物 | 织锦 / 缂丝 / 云锦 / 妆花缎 / 纱 / 罗 / 粗麻 | brocade / kesi silk / cloud brocade / figured satin / gauze / leno weave / coarse linen |
| 漆木 | 大漆 / 螺钿 / 剔红 / 腐朽木 / 包浆 | lacquer / mother-of-pearl inlay / carved lacquer / rotted wood / patina |

**工艺词库**

织金 gold-threaded ｜ 暗绣 hidden embroidery ｜ 盘金绣 couched gold embroidery
掐丝 filigree ｜ 錾刻 chased metalwork ｜ 鎏金 gilding ｜ 螺钿嵌 mother-of-pearl inlay
描金 gold tracing ｜ 点翠 kingfisher feather inlay ｜ 鎏金剥落 flaking gilding

**纹样词库**

云纹 cloud pattern ｜ 蟠龙 coiled dragon ｜ 缠枝莲 scrolling lotus
海水江崖 wave and mountain ｜ 十二章纹 twelve symbols ｜ 回纹 meander pattern
饕餮 taotie mask ｜ 联珠纹 pearl roundel

**为什么必须写工艺**：模型见过的"华丽服装"训练样本大多是廉价 CG，只写"华丽的衣服"会落在那个分布中心；写"织金云纹 + 盘金绣 + 掐丝"才把采样拉向真实工艺品的视觉特征。

### 支柱二｜景深层数（治平）

**三层铁律**：前景遮挡 + 中景主体 + 远景剪影，缺一不可。

| 层 | 作用 | 常用元素 |
|---|---|---|
| 前景 | 制造窥视感与空间厚度 | 香炉 / 柱础 / 帘幕 / 枝叶 / 肩背，压暗并虚化 |
| 中景 | 主体所在，唯一清晰层 | 人物 + 其接触的地面/道具 |
| 远景 | 交代世界规模 | 被雾气压成层叠剪影，**不要清晰模型** |

**气氛层要分层**：近处大颗粒虚化、远处小颗粒密集。均匀铺满 = 廉价特效。

**最低成本的大片手段：地面倒影。** 抛光石面、积水、湿润地面——几乎零提示词成本，换来最强的"贵"感。

---

### 支柱三｜光源物理性（治贴图）

**三层布光**

| 层 | 作用 | 要求 |
|---|---|---|
| 主光 | 定调，唯一的高光源 | 天光柱 / 穹顶透光 / 宫灯 / 法器 |
| 轮廓光 | 把人从背景剥离 | 侧逆光勾肩线与发丝 |
| 环境光 | 压住暗部，避免死黑 | 地面冷反射 / 远处雾光 / 火盆余光 |

**四条铁律**

1. 每道光必须有出处（天光 / 宫灯 / 法器 / 火盆 / 月），凭空发光 = 廉价特效。
2. 体积光必配介质（尘埃 / 烟雾 / 水汽），否则就是一张半透明贴图。
3. 暗部要"有内容的暗"，靠环境反射补一点，不要纯黑。
4. 冷暖对比至少一处：暖金主体光 + 冷蓝环境反射。

## 第三章 服饰豪华度 · 五层写法

只写「华丽的衣服」，AI 一定出塑料。必须分层给：

| 层 | 内容 | 示例 |
|---|---|---|
| 一 · 廓形 | 大袖礼服 / 广袖 / 曳地长裙 / 云肩 / 蔽膝 / 革带 | wide-sleeved ceremonial robe / cloud collar |
| 二 · 材质 | 织锦 / 缂丝 / 云锦 / 妆花缎 / 纱 / 罗 | brocade / kesi silk / figured satin |
| 三 · 工艺 | 织金 / 暗绣 / 盘金绣 / 掐丝 / 点翠 | gold-threaded / couched gold embroidery / filigree |
| 四 · 纹样 | 云纹 / 蟠龙 / 缠枝莲 / 海水江崖 | cloud pattern / coiled dragon / scrolling lotus |
| 五 · 配饰 | 禁步 / 玉带 / 步摇 / 璎珞 / 披帛 / 臂钏 | jade waist pendant / hairpin / silk shawl |

**三条必杀**

1. **层数不少于三**（外袍 + 中衣 + 披帛），每层材质词不同。
2. **必写垂坠褶皱与暗绣纹路**——布料的重力感是真人感的核心。
3. **配饰必须写动态**：随呼吸轻晃 / 随步伐相击 / 被气流掀起。**静止的配饰 = 贴图；会动的配饰 = 高级。**

## 第四章 场景豪华度 · 五层写法

| 层 | 内容 | 关键词 |
|---|---|---|
| 一 · 建筑结构 | 丹陛 / 蟠龙柱 / 藻井 / 飞檐 / 斗拱 / 阙楼 / 须弥座 | crimson steps / coiled-dragon pillar / caisson ceiling / upturned eave / bracket set |
| 二 · 材质 | 汉白玉 / 青石打磨如镜 / 做旧铜 / 大漆金柱 / 斑驳壁画 | white marble / polished bluestone / patinated bronze / lacquered pillar |
| 三 · 景深 | 前景遮挡 + 中景主体 + 远景剪影（三层齐全） | foreground occlusion / silhouetted layers |
| 四 · 气氛 | 纱幔 / 香烟 / 尘埃 / 雾气 / 水汽 / 落叶（**前后分层**） | gauze drapery / incense smoke / dust motes / atmospheric haze |
| 五 · 反光 | 地面倒影 / 金属高光 / 水面反射 / 湿润石面 | floor reflection / wet stone sheen |

**三条必杀**

1. 地面倒影是最高性价比的一招，成本几乎为零。
2. 远景务必"被雾气压成剪影"——层叠的模糊轮廓比清晰模型更贵、更史诗。
3. 气氛层分近远两层，不要均匀铺满画面。

## 第五章 灯光三层 · 豪华度底线

只用一盏光，画面必平必假。豪华镜头至少三层：主光 + 轮廓光 + 环境光（定义见第二章支柱三）。

**常见错误**

- 只有主光 → 死黑背景与塑料高光
- 只有轮廓光 → 主体悬空，无空间归属
- 三光同强度 → 平光，最廉价的布光
- 体积光无介质 → 半透明贴图
- 光源无出处 → 特效感

| 所有东西都崭新 | 至少一处旧化：剥落 / 锈蚀 / 褪色 / 包浆 |

## 第七章 三档豪华度（按镜头重要性选档）

| 档 | 规格 | 适用 |
|---|---|---|
| **A 档 量产** | 材质词 3 个 + 两层景深（主体 + 远景剪影）+ 主光与轮廓光各一 | 剧集量产镜头、过渡镜、远景群像 |
| **B 档 主力** | 材质词 5 个 + 三层景深 + 三层光 + 地面反光 + 一处旧化 | 宣传号、关键剧情镜、人物登场 |
| **C 档 顶配** | 材质词 8 个以上 + 前景遮挡 + 地面倒影 + 气氛分层 + 配饰动态 + 缓慢运镜 | 开场定调、大场面、高潮爆发、封面帧 |

**选档原则**：一部剧里 A 档占七成，B 档占两成半，C 档只给三五个镜头。**全是 C 档反而显不出贵**，对比才是豪华感的来源。

## 第十一章 ★ 颜色红线（2026-09-23 统一口径重测，权重最高的单条）

**这一章在 09-23 被整体推翻重写过。旧版方向是反的，且基准值抄错单位。以下为可复现版本。**

### 0. 先定口径，否则一切对比无效

测算统一用这套（脚本：`ai-video-diagnosis/scripts/diagnose.py` 或用交付过的单文件工具
`AI出片体检器.html`，两者算法一致、实测数字逐项吻合）：

| 指标 | 定义 | 作用 |
|---|---|---|
| 亮度中位 | HSV 的 V 通道中位数 /255×100 | 参考项，**不是判据** |
| 饱和中位 | HSV 的 S 通道中位数 /255×100 | 次要判据 |
| **艳溢像素** | **S > 70% 的像素占比** | **★ 主判据** |
| 暗部占比 | V < 35% 的像素占比 | 参考项 |
| 对比度 | V 通道标准差 /255×100 | 参考项 |
| 偏色幅度 | RGB 三通道均值的最大差 | 辅助 |

**旧版（09-22）的错**：把 0-255 尺度的通道**均值**当成百分比记录（于是出现「对标亮度 43/44/34」
「我方亮度 94」这类数）。同一条片换算成中位数是 32-75 区间。**单位一错，后面全错。**

我方 V4 成片（3 帧均值）：**39.3 / 42.1 / 17.7% / 44.2%**

### 2. 三条硬结论

1. **亮度、暗部在三条对标片之间波动极大（亮度 32→75，暗部 10%→58%）。**
   这是画面内容差异（夜戏/白天）造成的，**不构成判据**。谁把亮度当红线，谁就会误判。
   「暗调显高级」只对一半——难看的是「又暗又艳」，不是「亮」。
2. **艳溢像素三条全部≈0，与画面内容无关，是最稳的判据。**
   我方 17.7%，高出 170 倍。**廉价感的主因不是整体艳，而是「有一块艳到溢出」**——
   那一块肉眼很难自己发现，因为整张图看起来并不算艳。
3. **只测饱和中位会漏诊**：我方 42.1 vs 对标 27，只高 55%，单看并不刺眼；
   但同一张图的艳溢面积差了 170 倍。**必须看面积，不能只看中位。**

### 3. 调色方向（推翻 09-22 版）

**提亮 + 去色，不是压暗。**

原理（可验证）：`S = (max − min) / max`
- 提亮 → 三通道同加 → 分子不变、**分母变大 → S 自动下降**
- 压暗 → 分子不变、**分母变小 → S 自动上升**

**所以：压暗 = 加艳，提亮 = 去艳。** 这就是很多人「越调越脏」的机理：
先压暗（画面变艳）→ 再压饱和（颜色压没了、暗部也糊）。

### 4. 现行参数（09-23 网格搜索，在成片 3 帧上反推）

```
亮度 +24 / 对比度 0 / 饱和度 −30 / 高光 −12 / 阴影 0 / 暗角 +14
滤镜「褪色」或「电影感」30-40
```

实测落点（同一段成片）：

| | 调前 | 调后 | 对标均值 |
|---|---|---|---|
| 饱和中位 | 42.1 | **23.1** | 27 |
| 艳溢像素 | 17.7% | **0.02%** | 0.1% |
| 亮度中位 | 39.3 | **43.8** | 53 |
| 暗部占比 | 44.2% | **36.4%** | 29% |

四项一次全部落进对标区间。**对比度必须保持 0** —— 加对比度会推高亮部，饱和度随之反弹。

**顺序铁律：饱和度最后拖。** 先把亮度/高光/阴影/暗角调完，饱和度放最后一步。
理由即上面的 S 公式：任何后续的明暗改动都会改变 S 的读数。

### 5. 参数演进（两次方向性错误，务必保留）

| 版本 | 参数 | 实测落点 | 判定 |
|---|---|---|---|
| 早期 | 饱和 −40 | 降幅不够 | 不足 |
| 09-22 | 亮度 −45~−50 / 对比度 +20 / 饱和 −65~−70 | 亮度 **9.3**（死黑）、饱和 **49.7** | 方向错 |
| 09-23a | 亮度 −30 / 对比度 −10 / 饱和 −82 / 高光 −16 / 暗角 26 | 亮度 38.7、饱和 27 | **口径错，目标本身就是错的** |
| **09-23b（现行）** | **亮度 +24 / 对比度 0 / 饱和 −30 / 高光 −12 / 暗角 +14** | 四项全部落进对标区间 | **现行** |

**两条教训**：
1. **先把口径定死并写成脚本，再谈调色。** 口径一错，越努力越错——09-23a 那次搜索本身
   跑得很好、结果也自洽，但目标值来自错误单位，所以整套是废的。
2. **不要默认「压暗显高级」。** 亮度不是判据。先测艳溢面积，再决定往哪个方向调。

### 6. 交付红线

1. 每个发货包必须附**参数 + 落点数值**（调完能到什么数），不能只给参数。
2. 判据是数值不是感觉：**艳溢像素目标 ≈0，红线 >5%；饱和中位红线 >34。**
3. 平台压缩会影响读数（抖音/微信转码压亮度与饱和），**相对差异有效、绝对值偏保守**。
4. **调色只解决颜色这一层**：蜡像感的脸、平光光影、贴图材质调色救不回来，必须重出首帧图。
   不要把调色说成万能解——那是过度承诺。

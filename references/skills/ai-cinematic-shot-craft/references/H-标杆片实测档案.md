import cv2, numpy as np
p = r'<视频绝对路径>'
c = cv2.VideoCapture(p); fps = c.get(cv2.CAP_PROP_FPS)
prev = None; d = []; lum = []; sat = []
while True:
    ok, f = c.read()
    if not ok: break
    g = cv2.cvtColor(cv2.resize(f, (64, 64)), cv2.COLOR_BGR2GRAY)
    hsv = cv2.cvtColor(cv2.resize(f, (64, 64)), cv2.COLOR_BGR2HSV)
    lum.append(float(hsv[:, :, 2].mean())); sat.append(float(hsv[:, :, 1].mean()))
    if prev is not None: d.append(float(np.mean(np.abs(g.astype(int) - prev.astype(int)))))
    prev = g
d = np.array(d); l = np.array(lum); med = np.median(d)
cuts = [i for i, v in enumerate(d) if v > max(med * 4, 18)]
m = []
for i in cuts:
    if m and i - m[-1] <= 5: continue
    m.append(i)
print('时长', round(len(d) / fps, 1), '秒')
print('硬切', len(m), '次，平均镜长', round((len(d) / fps) / max(len(m), 1), 2), '秒')
print('切点(秒):', [round(i / fps, 1) for i in m])
print('亮度中位', int(np.median(l)), '| 最大', int(l.max()))
print('动作强度均值', round(d.mean(), 1))

## 九、★ 静止许可放大律（2026-09-22 定，写打斗提示词的第一铁律）

| 提示词里我写了 | 实拍变成 | 放大倍数 |
|---|---|---|
| 「两刃顶死**静止一拍**」（本意 0.8 秒） | 静止 **2.5 秒** | ×3 |
| 「凝冰霜巨轮、星尘**缓缓上升**、两人**沉腰低伏**」 | 一个 **8.5 秒**长镜，只有一人在飘 | ×5 |

所以「提示词没写满」的反面同样致命——**不是写得不够多，是写了不该写的静止**。
写打斗时，动作序列里禁止出现上述词；**静止只允许用带明确时限的写法**（如「保持交错姿态定住半秒」）。

### 调色方向（修正第十章）

**提亮 + 去色，不是压暗。** `S=(max−min)/max` → 提亮使分母变大、S 自动下降；
压暗使分母变小、**S 反而升高**。即 **压暗 = 加艳**，这就是「越调越脏」的机理。

```
亮度 +24 / 对比度 0 / 饱和度 −30（最后拖）/ 高光 −12 / 阴影 0 / 暗角 +14
```

落点：饱和 42.1→**23.1**、艳溢 17.7%→**0.02%**、亮度 39.3→**43.8**、暗部 44.2%→**36.4%**。

## 十四、环境型持续事件的三层写法（2026-09-23 金莲案例，通用方法论）

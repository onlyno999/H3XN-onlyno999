二、服饰 · 豪华度五层写法
────────────────────────────────────────

只写"华丽的衣服"，AI 一定出塑料。必须分层给：

第一层  廓形    大袖礼服 / 广袖 / 曳地长裙 / 云肩 / 蔽膝 / 革带
第二层  材质    织锦 / 缂丝 / 云锦 / 妆花缎 / 纱 / 罗 / 大漆 / 皮革
第三层  工艺    织金 / 暗绣 / 盘金绣 / 掐丝 / 錾刻 / 鎏金 / 螺钿 / 点翠
第四层  纹样    云纹 / 蟠龙 / 缠枝莲 / 海水江崖 / 十二章纹 / 回纹
第五层  配饰    禁步 / 玉带 / 步摇 / 璎珞 / 披帛 / 帔子 / 臂钏 / 香囊

服饰必杀技：
  · 层数不少于三（外袍 + 中衣 + 披帛），每层材质词不同。
  · 必写"垂坠褶皱"与"暗绣纹路"——布料的重力感是真人感的核心。
  · 必写配饰的"动态"：随呼吸轻晃 / 随步伐相击 / 被气流掀起。
    静止的配饰 = 贴图；会动的配饰 = 高级。

三、场景 · 豪华度五层写法
────────────────────────────────────────

第一层  建筑结构  丹陛 / 蟠龙柱 / 藻井 / 飞檐 / 斗拱 / 阙楼 / 廊柱 / 须弥座
第二层  材质      汉白玉 / 青石打磨如镜 / 做旧铜 / 大漆金柱 / 螺钿嵌饰 / 斑驳壁画
第三层  景深      前景遮挡物 + 中景主体 + 远景建筑轮廓（缺一不可）
第四层  气氛      纱幔 / 香烟 / 尘埃 / 雾气 / 水汽 / 落叶（要有前后分层）
第五层  反光      地面倒影 / 金属高光 / 水面反射 / 湿润石面反光

场景必杀技：
  · 地面倒影是最高性价比的一招，几乎零成本换来大片感。
  · 远景一定要"被雾气压成剪影"——层叠的模糊轮廓比清晰的模型更贵。
  · 气氛层要有前后分层：近处大颗粒虚化、远处小颗粒密集，不要均匀铺满。

────────────────────────────────────────
四、灯光 · 三层布光（大片的底线）
────────────────────────────────────────

只用一盏光，画面必平必假。豪华镜头至少三层：

主光    天光柱 / 穹顶透光 / 宫灯 —— 定调，唯一的高光源
轮廓光  侧逆光勾肩线与发丝 —— 把人从背景里剥离出来
环境光  地面冷反射 / 远处雾光 —— 压住暗部，避免死黑

灯光铁律：
  · 每道光都必须有出处（天光 / 宫灯 / 法器 / 火盆），凭空发光 = 廉价特效。
  · 暗部要"有内容的暗"：靠环境反射补一点，不要纯黑。
  · 冷暖对比至少一处：暖金主体光 + 冷蓝环境反射。
  · 体积光必须配介质：光柱里要有尘埃或烟雾，否则是贴图。

五、去廉价感对照表（最实用，直接照改）
────────────────────────────────────────

廉价写法                      改成这样
─────────────────────────────────────────────────────────
满屏金色粒子飞舞        →  单一天光柱，柱内少量尘埃缓慢翻滚
华丽宫殿                →  汉白玉阶 + 蟠龙金柱 + 藻井 + 纱幔，指定材质
金色长裙                →  织金云纹大袖礼服 + 缂丝披帛 + 掐丝银冠 + 玉禁步
高饱和七彩              →  三色控制：主金 / 辅青 / 点缀朱红，低饱和
快速甩镜、频繁切镜      →  缓慢推轨或缓升，一次运镜走完
完美无瑕的脸与衣服      →  加褶皱、磨损、鎏金剥落、灰尘、氧化
空旷背景                →  三层景深 + 前景虚化遮挡
能量光球乱飞            →  能量有形状有来源：扇形 / 柱形，从法器发出
人物全身清晰            →  浅景深，背景虚化，前后分离
亮部一片死白            →  保留高光细节，降低整体曝光半档
地面什么都没有          →  加倒影、积水、碎屑、青烟
配饰静止不动            →  写动态：随呼吸轻晃 / 相击 / 被气流掀起

七、校验清单
────────────────────────────────────────

[√] 材质词不少于 5 个（材料 + 工艺 + 纹样）
[√] 服饰不少于三层，且配饰写明了动态
[√] 场景三层景深齐全：前景遮挡 + 中景主体 + 远景剪影
[√] 地面有倒影或反光
[√] 灯光三层：主光 + 轮廓光 + 环境光
[√] 每道光都有物理出处
[√] 体积光内配了介质（尘埃 / 烟雾）
[√] 至少一处"不完美"（磨损 / 剥落 / 褶皱 / 灰尘）
[√] 三色控制，低饱和
[√] 运镜为缓慢单一运动，非快切快摇
[√] 无背景音乐，无字幕

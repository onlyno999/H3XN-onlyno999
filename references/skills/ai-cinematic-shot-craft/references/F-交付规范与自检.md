## 零、成片密度红线（最高优先，出片空就查这里）

> **参照系唯一来源 = H 卷「标杆片实测档案」**（用户本人发来的片，逐帧量化）。本表所有数字都出自那里，不准凭感觉改。用户发新片 → 先按 H 卷第六章脚本量化入库 → 再排镜。

2026-09-22 复盘：一条 30 秒双人对打投喂 Seedance 2.5，出片前 8 秒两人站着不动、中段三帧画面几乎一样、全片只出现一次武器交叉和一次剑气。原因是**提示词把算力喂给了场景，没喂给动作**。

### 四个病根与对策

| 病根 | 成片表现 | 对策 |
|---|---|---|
| 场景词过量 | 前几秒只有环境空镜、人物站定 | **每段场景句只留 1 句**，位置固定在段首；其余全给动作 |
| 动作写成概述 | 模型只抓最显著一个动作反复播放，相邻帧几乎相同 | 拆成**连续动作串**：每 1-1.5 秒一个动作 ＋ 一个受力反馈 |
| 动作之间有停顿 | 打一下停一下，像摆 pose | 用「紧接着／不等落地便／随即／被震开后立刻」串联，不许停顿 |
| 缺同框约束 | 模型自动拆成单人镜头，两人从不交手 | 每镜写明「双人同框贴身交手」，负面词加 `split screen` |

### 密度档位表（两条标杆片实测，2026-09-22）

| | 标杆一 | 标杆二 |
|---|---|---|
| 时长 | 35 秒 | 17.5 秒 |
| 硬切次数 | 8 | 8 |
| **平均镜长** | **4.4 秒** | **2.18 秒** |
| 动作强度均值 | 2.8 | **6.3** |
| 闪白 | 无 | 有 1 次（全片 58% 处） |
| 颜色 | 见 B 卷第十一章 | 同左（口径已统一） |

**规律**：片子越短切得越快、打得越猛。但两片共同点是**硬切总数都只在 8 次上下**，不是切得越多越好。

**按片长选档**：

| 目标时长 | 拆段 | 镜数 | 每镜秒数 | 每镜动作数 |
|---|---|---|---|---|
| 15 秒 | 3 段 × 5 秒 | 6 | 2.5 | 3 |
| 30 秒（猛档，推荐） | 6 段 × 5 秒，段内切一次 | 12 | 2.5 | 3 |
| 30-35 秒（稳档） | 6 段 × 5-6 秒，段内不切 | 6-8 | 4-5 | 4-5 |
| 60 秒 | 12 段 × 5 秒 | 24 | 2.5 | 3 |

**段内最多切一次**（一段 2 镜）。接缝次数越少脸越稳，密度靠镜内动作数，不靠增加切点。

其余硬指标：

- 曾犯过的错：以为"密度＝每 1.2 秒切一镜"，30 秒排 24 镜 → 画面碎、每次切镜重新构图、易崩。**不要碎切**
- **开场静止 ≤1 秒**（允许一拍对峙），之后必须一直在动
- **颜色门槛**：艳溢像素 ≈0、饱和中位 ≤30（亮度不是判据，详见 B 卷第十一章），闪白全片最多 1 次，放在 55-60% 处
- **每段 EN 提示词 ≤ 200 词**；超了先删场景词与格式后缀，动作串必须原样保留
- 每镜必须含：景别/跟拍方式 ＋ 双人同框声明 ＋ 动作流 ＋ 反馈 ＋ 特效来源

### 段内写法模板（一镜到底）

```
开场一拍：两刃顶死，尘埃在天光柱中翻滚
紧接着：A 动作，B 受力反馈
不等站稳：A 动作，B 受力反馈
随即：A 动作，B 受力反馈
全程不停顿、不摆姿势、镜头持续跟随，双人始终同框
```

## 三、两道自检（**必跑**）

### 自检 1 · 中文区扫孤立英文

Windows 分行换行不稳会导致中英串字（曾出现过「同一 recommence 能量色相 trees」「半空交错起 Ice 轮」这类）。脚本：

```python
import re
p = r'D:\桌面\你的文件.txt'
lines = open(p, 'rb').read().decode('utf-8-sig').split('\n')
en = False; bad = []
for i, l in enumerate(lines, 1):
    if 'EN 提示词' in l: en = True; continue
    if any(k in l for k in ['中文提示词', '关键点', '画面还原', '负面词', '音效']) or l.startswith('────'): en = False
    if en: continue
    for m in re.findall(r'[A-Za-z]{3,}', l):
        bad.append((i, m))
print('中文区英文残留:', bad if bad else '无')
```

白名单：`handle / pose / AIGC / Seedance / GFSM / 视频 hash 名`。扫到即修，**不要放过**。

### 自检 2 · 转码与完整性

```python
p = r'D:\桌面\你的文件.txt'
d = open(p, 'rb').read().replace(b'\r\n', b'\n').replace(b'\n', b'\r\n')
if d.startswith(b'\xef\xbb\xbf'): d = d[3:]
open(p, 'wb').write(b'\xef\xbb\xbf' + d)
b = open(p, 'rb').read(); txt = b.decode('utf-8-sig')
print('BOM:', b[:3] == b'\xef\xbb\xbf', '| CRLF:', b.count(b'\r\n'),
      '| 裸LF:', b.count(b'\n') - b.count(b'\r\n'), '| 管道表:', '|' in txt)
```

合格标准：BOM True、裸 LF = 0、管道表 False。

## 标准交付模板（用户 2026-09-21 定档：不多不少）

颗粒度校准：三句极简版 = 太少；八章带原理说明 = 太多。正确档位是**全部结构化字段都有，但零解释性文字**。

单镜头交付固定九章：

1. 空间与光源契约（唯一光源／景深三层／三锚点／三色控制／主体 handle）
2. 时间轴（精确到 0.1s 的分段节拍）
3. 中文提示词（成品，直投）
4. EN 提示词（带 --no bgm subtitle）
5. 音效设计（无 BGM，静默段要标明「一声不填」）
6. 负面词（通用 + 题材专属）
7. 宣传号版本（钩子前置，首尾可循环；若用户已定用途则只出对应版本）
8. 拆镜备选（A/B 段起止 + 接缝要点）
9. 校验清单（10 条以内，每条一句）

**禁止出现**：原理说明段、为什么这么写、常见错误分析、表格外的技术注释。约束要写进提示词本身或契约字段，不要写在正文里解释。

**排版**：不用 markdown 管道表（用户明确不要），用缩进 + 全角符号对齐。

```python
import re
```

## 零之二 · 两条必守铁律（2026-09-22 血泪，优先级高于排版规范）

### 铁律一 · 静止许可放大律

提示词里**每一个**「静止 / 凝 / 沉 / 缓缓 / 衰减 / 沉落 / 停 / 低伏」的许可，
生成模型都会**放大 3 到 5 倍**执行。实测对照：写「静止一拍」（想 0.8 秒）→ 出 2.5 秒；
写「凝光 + 沉腰低伏」→ 拉成 8.5 秒长镜；写「滑停 + 半跪 + 灵光衰减」→ 收尾静止 3.5 秒。

- **动作序列内禁用上述词**。
- **静止只能写成带时限的形式**：「保持交错姿态定住半秒」「画面收住」。
- 检查动作满不满，不看写了几个「招」，看**动作推进词**够不够：
  「紧接着 / 不等落地便 / 随即 / 立刻 / 被震开后立刻 / 再劈 / 再扑 / 再冲」。
  一个 2.5 秒镜至少 1 个推进词，一段 5 秒至少 2 个。
- **长镜不空的前提是镜内全程有动作**。标杆片能做到 17 秒不切镜，是因为那 17 秒强度持续 3-5.5；
  若镜内没动作，8.5 秒长镜就是死的。

### 铁律二 · 调色不归提示词管，必须后期

提示词里写「暗调低饱和」没用——生成模型不执行调色指令。
**这是「一个天一个地」的最大来源，权重高于提示词本身。**

**口径与实测数据见 B 卷第十一章，本节只列执行参数（09-23 第三次修订，此前两版方向错）。**

**每个交付包必须附剪映调色参数 + 落点数值**：

```
亮度 +24 / 对比度 0 / 饱和度 −30 / 高光 −12 / 阴影 0 / 暗角 +14
```

实测落点：饱和中位 42.1→**23.1**、艳溢像素 17.7%→**0.02%**、亮度 39.3→**43.8**、
暗部 44.2%→**36.4%**（四项一次全部落进对标区间）。

- **主判据是艳溢像素，不是亮度**：S>70% 的像素占比，对标三条全部 ≈0，红线 >5%。
  亮度在三条对标片间波动极大（32→75），**不是判据**。只测饱和中位会漏诊。
- **方向是提亮 + 去色，不是压暗**。`S=(max−min)/max` → 提亮使分母变大、S 自动下降；
  压暗使分母变小、**S 反而上升**。即：**压暗 = 加艳**。这是「越调越脏」的机理。
- **饱和度必须最后拖**：任何后续的明暗改动都会改变 S 的读数，先拖会白调。
- **对比度保持 0**：加对比度会推高亮部，饱和度随之反弹。
- **判据是数值不是参数**：调完必须达到 **艳溢像素 ≈0（红线 5%）、饱和中位 ≤30（红线 34）**。
- 调色只解决颜色这一层；蜡像脸、平光、贴图材质救不回来，得重出首帧图。别过度承诺。
- 这条做完，观感与之前完全不同，成本为零，是最划算的一步。

### 成片自查的黄金口径（逐 0.5 秒帧差曲线）

不要只看「切了几刀」。**逐 0.5 秒算帧间差**打印曲线，找**强度掉到峰值 18% 以下的连续区间**——
那就是空档。本片就是这样抓出「6.5-13 秒」这个 6.5 秒死穴的
（单看「12 镜」这个数字完全看不出来，因为碎切把平均数拉高了）。

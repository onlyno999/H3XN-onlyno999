## 🧭 这是什么

一套 **给 AI 助手执行的打斗规则库**（OpenClaw Skill / Agent 技能包），不是提示词模板仓库——把 `SKILL.md` 与 `references/` 放进 Agent 技能目录即可调用。

**核心用途只有一个：打斗提示词重写。**

你丢一段**现成的打斗提示词**进来（自己写的、别家的、小说改的、随手糊的），它按 R1 写实克制口径重写成**可直接投喂视频模型的七段式成品**，顺手把里头的毛病治掉。

## 🚫 它治什么病

| # | 病灶 | 为什么必须治 |
|:---:|:---|:---|
| 1 | **静止段**（对峙 / 蓄势 / 悬停 / 站定亮相） | AI 视频没有"静止表演"能力，必被渲染成**呆立** |
| 2 | **站桩式对打**（两人站定轮流出招） | 与真人打斗的力学完全不符，P0 阻断 |
| 3 | **抽象打斗词**（"快速连打""挥拳打去""打作一团"） | 无受力、无落点，模型当挥手处理 |
| 4 | **特效词**（光波 / 冲击波 / 法阵 / 粒子） | R1 写实档禁用，写了就成玄幻 |
| 5 | **血腥拦截词**（打断骨头 / 血肉横飞） | 平台会拦；需转译为物理受力描写 |
| 6 | **套路照搬**（照抄 12 式顺序、"A→B→C"箭头链） | 库内是拳套固有顺序，不是战斗顺序 |
| 7 | **90° 正拍中景全景** | 街机横版廉价感，丢纵深 |
| 8 | **版本语法混写**（2.0 里写 2.5 的 `{}` / `<>`） | 两个版本的契约彻底分流，混写必废 |
| 9 | **多人场景「轮流出招」**（甲打完退下、乙再上） | 多人版站桩 = P0；没轮到的人会被渲染成原地待命 |
| 10 | **同款服装导致分身**（三个同款黑衣人 = 一个人被复制三次） | 需 ≥2 项外形差异锚点 + 专属负面词 |

## 📏 三条节奏硬口径

> 违者 **P0 阻断**。这三条是本包与"照抄招式库"的分水岭。

**① 机关枪式近景对招**
近景对招段一律用**序列化招式链**：全链 **2~3 秒内 6~10 击**、**击与击之间零间隔**（打出即收、收即出）、守方**逐击反应不同并带步法位移**。禁"两人快速对打"这类模糊写法。

**② 升格慢镜默认 0 处**
实测破坏节奏。仅用户明确要求且全片 ≤1s 可用；命中瞬间 1~2 帧微顿（Hit-Stop）**仅 2.5 可用**、不计入升格。

**③ 严禁站桩式对打**
两人站定轮流出招、或原地打完整套 = 阻断。所有招式必须**挂在步法位移或重心转换上**（抢步 / 绕侧 / 撤步 / 换位 / 低伏）。

> **取神不取形**：招式库只取「招式名与外形特征 / 劲力原理与发力方向 / 打击部位与受力反馈」三样；衔接与节奏一律以本包为准——**禁照搬库内套路顺序与箭头链**。

## 👥 多人战斗（同场 2~4 人）

> ★ 唯一真源：`references/multi-opponent-rules.md`。出现「两人以上同场交手 / 以少打多 / 一打多 / 围攻 / 群战 / 2v2 / 3v3」→ **必读**。该文件**覆盖** 1v1 默认写法（轴线锁定 / 开局构图 / 站位声明 / 景别策略），六条铁律继续生效。

| 机制 | 口径 |
|:---|:---|
| **人数上限** | 同场 2~4 人；同镜「正在交手」≤3 人；**特写禁 ≥3 人**；5 人以上拆成若干 2~4 人子场 |
| **主角唯一锚点** | 全部运镜围绕主角；**主线镜头主角必须在场**；**焦平面 ≤2 人**（第三人只作移动前景 / 焦外剪影）|
| **多轴管理** | **主轴**（主角 ↔ 当前主要对手，全段禁越轴）+ **从轴**（其余人侧位，同镜内不得反向）；主轴切换只有三种合法时机（击退 / 主动转身 / 新威胁介入），**禁瞬切** |
| **三拍轮转制** | 同一时间最多一人与主角实际接触；其余人必须处于**压上 / 被击退 / 绕位**之一；任一角色 **≥1s 无位移无受力 = 站等 = P0 阻断** |
| **多人节拍弧** | 接敌 → 被围 → **破围点** → 逐个击破（**节奏加速**）→ 收势；8~12s 拐点从「逆转」挪到「破围点」 |
| **群像镜头** | 人越多镜头越收紧：过肩带出第二人、多人同框借前后遮挡分层；**视线引导切为强制**（主角看向新威胁 → 下一镜必须切过去）|
| **防分身** | 每个非主角**至少 2 项外形差异**（体型 / 发型 / 服装 / 兵器 / 站位习惯）；负面词追加 `同一人物重复出现 / 服装互换 / 人物融合 / 同脸复制` |
| **时长镜数** | 1v2 → 4~5 镜；1v3 → 5~6 镜；2v2 / 3v3 → 直接拆 2 组（每组聚焦一条主轴线）|
| **站位声明** | 改**三行制**：主轴行（含轴线锁定）+ 从轴行 + 全员动态行（逐人 `起点→终点` + 动作原因）|

## ⚙️ 快速开始

**安装**——把 `SKILL.md` 与 `references/` 放进 Agent 技能目录：

```
# OpenClaw
~/.openclaw/workspace/skills/real-combat-director/
```

**给 AI 助手的最小执行序列**：

```
读 SKILL.md → 完成 A（模型版本）+ B（画幅）锁
→ 分清输入是重写还是新建 → 有打斗必过 kinetic-chain-11 + impact-physics
→ 按 render-adapters 七段式封装 → 出稿前过 S5 机检清单 → 交付
```

## 🕹️ 指令路由

| 指令 | 动作 |
|:---|:---|
| `/定档` 或 `初始化打斗项目` | S1：锁模型版本 + 画幅，确认题材/人物/场景/时长，输出项目头 |
| `/拆招` 或 `设计动作` | S2：11 环动力链推导关键重击，招式库选招，写清每击的落点/受力/状态继承 |
| `/做分镜` 或 `镜头设计` | S3：按 R1 档输出镜头规格五要素分镜表 |
| `/投喂提示词` | S4：输出 Seedance 2.5/2.0 七段式投喂封装 |
| `/审查` 或 `/质检` | S5 + S6：机检清单逐项过，输出 P0/P1/P2 结论与《改动复验报告》 |
| `/看板` | 把项目 md 编译为单文件离线分镜看板 |

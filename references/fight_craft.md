# fight-craft-onlyno999 · 打戏工艺总库

## Purpose
一套蒸馏后的打戏写词规程：不论投喂哪个模型、先过这本的九条工艺，再按题材回源包查细节。目标是治打戏的六种老病——慢热、发软、相持发呆、单向挨揍、人物跑散、终结单薄。

## Workflow（写一条打戏词的顺序）
1. **定档**：先判写实档还是玄幻档，全程不混。
   - 写实档（现代格斗/警匪/喜剧/真人）：克制、真实招式、受力真实，慢镜默认 0 处；深查 `real-combat-director`。
   - 玄幻档（修仙/仙法/神魔/国漫）：特效尺度拉满、三轮攻守骨架；深查 `xuanhuan-combat-director`。
2. **搭骨架（节奏）**：总时长先切拍——开场拍（≤1.5s 必须第一次攻防接触，第一帧不许全景铺垫）→ 中段交锋拍（每 2–3 秒一个整拍，一拍只装一个核心攻防）→ 终结拍（留足全片约四分之一给终结技）。快慢要有呼吸：连续同节奏不超过约 5 秒，重招前留半拍蓄势、重招后留余波。
3. **填招式（序列化）**：每拍写成可数的招式链，不写抽象词——逐招点名（哪只手/哪件兵器、打向哪个落点）、对手的回应（闪/格/卸/反）与受力回执（后退几步、兵器震颤、地面裂开、火花飞溅）三件齐全。禁写「快速连击」「激烈交锋」这类没法拍的定性词。
4. **锁空间**：全场预设 2–3 个空间锚点（门/桩/台阶等），换位只在锚点之间写明路径；结尾按收束四选一落位：A 遗物定场（兵器/信物留在画面定格空间）/ B 物理抛飞隔离（败者被打飞出画或隔开）/ C 光粒湮灭（败者化光粒消散）/ D 永动硬切（胜者不停步、错身出画硬切收尾）——严防爆炸/终结后人物在原地凭空刷新。
5. **挂特效（玄幻档）**：一镜 1–2 个特效元件封顶，特效颜色全片控制在两个色系内；施法/爆炸的命中瞬间可加一记**冲击帧**——单帧全屏闪白＋冲击波圆环＋镜头猛震后缓慢回稳；注意冲击帧是光爆不是停顿，动作一帧不停（与「全程高速、无慢镜无定格」铁律并行不悖）。
6. **终结技三段式**：前摇蓄压（能量向心压缩、异象先行）→ 主体成形（有宏观厚度的实体形态，不许一根单薄光条）→ 横推碾压（沿途斩碎/推平对手的造物与防线，落点明确）。属性选系后整场不换系；属性库深查 `seedance-fantasy-ultimate-prompt`。
7. **落词前自检**（逐项过，缺一回炉）：
   - [ ] 第一拍 1.5s 内有接触？开场没有全景铺垫？
   - [ ] 每拍只有一个核心攻防、且攻/防/受力三件齐？
   - [ ] 全文没有长时状态动词（持续对峙、双手横架推搡、僵持）？动词都是瞬发瞬收？
   - [ ] 对手有正向致命输出，不是沙包？攻守至少轮换三轮（玄幻档）？
   - [ ] 人物换位都写了路径、没瞬移？收尾用了 A/B/C/D 之一？
   - [ ] 特效 ≤2/镜、色系 ≤2？冲击帧只在命中瞬间、没写成定格？
   - [ ] 终结技三段齐、留时够（约占全片 1/4）？
   - [ ] 速度是动作本身的快（写进招式密度），没有靠慢镜/变速凑？

## Output Contract
输出仍按投喂目标的原生格式走（H3 六段式 / Seedance 时间线等由对应生产线技能管），本技能只管其中的**打戏内容质量**：骨架拍表（每拍：时码/机位景别/攻方招式/守方回应/受力回执/空间锚点）先行，正词随后；交付时说明本条用了哪几条工艺、回查了哪个源包。

## Operating Rules
1. 本技能是方法层，不含出口与派发口径；出片走当次点名的生产线（H3XN/H3PRO/Seedance 等），不许拿本技能替代生产线的 SKILL.md 流程。
2. 与用户既有铁律冲突时用户铁律优先：全程高速、绝无慢动作/定格（冲击帧是唯一例外且只许单帧光爆）；速度写进动作本身不许后期变速；脸只靠参考图锁、不写五官形容词。
3. 蒸馏口径与源包原文冲突时，以源包为准并回读源包对应章节，不凭本页概括下词。
4. 源包索引（本机 `~/workspace/skills/` 下）：`seedance-combat-prompt`（完播率公式、流派技法与兵器资料库）、`seedance-high-impact-combat-GFSM`（空间锚点与攻防成对细则）、`ai-spell-impact-lens`（冲击帧/震屏字段模板）、`seedance-fantasy-ultimate-prompt`（九系大招库）、`ai-cinematic-shot-craft`（镜头类型/质感/特效元件/节奏八卷）、`xuanhuan-combat-director`（玄幻导演全系统，H3XN 组件三）、`real-combat-director`（写实档动力链与多人调度）、`short-drama-director`（全流程门控与机检，漫剧老李 V6.9.9）。
